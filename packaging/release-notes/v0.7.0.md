# Licasa 0.7.0 release notes

Licasa 0.7.0 improves large-image viewing and prepares the first stable Snap
release while retaining the existing image formats, editing tools and Linux
installation packages.

### Viewing and playback

- Reuse full-resolution pixels retained by preview decoding and bring ready
  images into full detail sooner.
- Add a fast preview path for eligible WebP images and improve PNG preview
  conversion and scaling for large photos.
- Bound nearby preview work so opening a large AVIF or WebP does not compete
  with unnecessary background decodes.
- Preserve HEIF worker contexts until their decoded tiles are finished, and
  retain the bounded parallel HEIF and JPEG 2000 decoding optimizations.
- Avoid a transient error frame when a failed preview switches to a usable
  fallback.
- Correct paused Motion Photo seeking at an exact frame boundary.

### Snap and Linux packages

- Package the Snap with stable grade and strict confinement. The checked Store
  revision is first verified on edge, then promoted to stable by the separate
  release approval workflow.
- Keep Ubuntu 24.04 amd64 as the native library baseline and retain the private
  Qt 6.4.2 runtime fixes, maintained image codecs and lazy Motion Photo backend.
- Retain AppImage, Debian, Fedora RPM and Arch packages with SHA-256 checksums.

### Release builds

- Reuse the tested Debian payload when packaging the Snap from the same release
  run, with source, version, architecture and checksum checks.
- Cache exact dependency builds and bounded compiler outputs. Full selected
  tests and installed-package checks remain part of the release pipeline.
- Retain new CI artifacts for seven days and avoid recompressing package files.

These changes do not claim new benchmark results. Physical GPU and desktop
compatibility depend on the user's system; the release pipeline checks clean
installations with virtual X11 and Wayland displays.

### Release files

- `Licasa-0.7.0-x86_64.AppImage` and `install-licasa-appimage.sh`
- `licasa_0.7.0-1_amd64.deb`
- `licasa-appimage-0.7.0-1.fc44.x86_64.rpm`
- `licasa-appimage-0.7.0-1-x86_64.pkg.tar.zst` and its `PKGBUILD`
- `licasa_0.7.0_amd64.snap`

Each package has a matching SHA-256 file. Snap installation after stable
publication uses `sudo snap install licasa`. Background mode remains optional.
