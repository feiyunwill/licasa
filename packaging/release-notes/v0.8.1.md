# Licasa 0.8.1 release notes

Repairs Debian 13 (Trixie) installation and photo-opening failures reported in [issue #3](https://github.com/sanxchep/licasa/issues/3), with regression coverage across the supported Linux packages.

## Installation and file dialogs

- Add a separate Debian 13 native package with matching Qt and multimedia libraries. The Ubuntu native package remains specific to Ubuntu 24.04.
- Include the complete fallback file-picker runtime and portable library dependencies. Verify the final package contents before adding desktop test tools.
- Keep failed dialog imports recoverable, preserve the current photo and edits, and allow retrying. Escape cancels the picker, restores focus, and does not activate background viewer shortcuts.
- Verify native GTK Open and Save As on Debian, including selecting a photo, preserving edits, cancelling, reopening, and decoding the saved output.

## Playback and accessibility

- Fix a Qt 6.4 multimedia startup race that could leave a Motion Photo loaded without producing frames. Retain fixes for custom-input cleanup, paused seeking, rotated frame capture, and conversion of video frames on the GUI thread.
- Improve keyboard focus, accessible names, roles, states and values for photo opening, dialogs, crop and adjustment controls, and error notifications. MATE checks exercise AT-SPI and Orca event processing; audible announcement order and other desktop accessibility combinations remain separate acceptance work.

## Regression prevention

- Exercise Open, Cancel, keyboard reopen, Save As, edited output and lazy export pickers against installed production packages on X11 and Wayland with default and software rendering.
- Test supported image readers and Motion Photo controls, seeking, rotation, frame saving and teardown. Include deterministic negative controls for missing modules, runtime provenance and the multimedia startup race.
- Drive the support table and required package matrix from one manifest. Stable promotion requires complete evidence for the exact source commit and package hashes; failed, skipped and unsupported outcomes cannot stand in for required passing tests.
- Retain failed evidence and reuse unchanged packages only for verified qualifier changes. Installation and crash issue forms collect the package and distribution details needed to reproduce a report.
