# Licasa 0.7.1 release notes

Licasa 0.7.1 improves Linux installation checks and release verification while
retaining the viewing, decoding and editing optimizations from 0.7.0.

### Installation

- Check the host architecture, glibc tools and bundled runtime libraries before
  replacing an existing AppImage installation.
- Explain missing tools, extraction failures and incompatible libraries with
  clearer guidance. Keep the existing installation when those checks fail.
- Check Debian and AppImage dependencies in clean Ubuntu environments before
  installing desktop test tools, so those tools cannot hide missing libraries.
- Bundle the X11 session and bidirectional-text libraries needed by Qt and
  multimedia plugins, including on minimal desktop installations.

### Verification

- Report unavailable OpenCL and CUDA devices as skipped tests in CTest and CI
  reports. Required GPU checks and test failures still fail the run.
- Run installer regression checks before the release build starts.
- Save successfully built private dependencies before installation checks, so a
  later packaging failure does not discard that reusable work. Packaging-only
  workflow edits no longer invalidate the dependency cache.
- Add a separate manual workflow to check published packages on additional
  Ubuntu versions and normal Snap launches in nested GNOME and KDE sessions.
  These checks reuse release files without rebuilding or publishing them.

The additional qualification workflow is separate from the release build.
Its results are required before claiming broader Ubuntu or desktop coverage.
Nested desktop checks use software rendering on hosted VMs; physical AMD/Intel
graphics and driver coverage remains untested.

### Packages

The Snap keeps stable grade and strict confinement. Release builds continue to
reuse the verified Debian payload for Snap packaging, cache exact dependencies,
and check package versions and checksums before publication. Stable promotion
follows qualification of the checked edge revision.

- `Licasa-0.7.1-x86_64.AppImage` and `install-licasa-appimage.sh`
- `licasa_0.7.1-1_amd64.deb`
- `licasa-appimage-0.7.1-1.fc44.x86_64.rpm`
- `licasa-appimage-0.7.1-1-x86_64.pkg.tar.zst` and its `PKGBUILD`
- `licasa_0.7.1_amd64.snap`

Each package has a matching SHA-256 file. The native Debian package targets
Ubuntu 24.04 amd64. Background mode remains optional.
